The storefront's only button. Also used as an inert label (price tag, product name over an image).

```jsx
<Chip href="/collections/all">Shop</Chip>
<Chip glyph href="/discover">Discover Launch Collection</Chip>
<Chip variant="submit" as="button" type="submit">Sign up</Chip>
<Chip variant="price">$189</Chip>
```

Hover inverts default/price chips to ink-on-white→white-on-ink; submit chips go navy.
